# Free Trade Journal Template

Free trade journal template for Excel, Google Sheets and print: one row per trade, with working P&L, R-multiple, win rate and drawdown. No email required.

Get the template at https://tradejournaltemplate.com/

## Formats

- Excel: https://tradejournaltemplate.com/excel/
- Google Sheets: https://tradejournaltemplate.com/google-sheets/
- Printable: https://tradejournaltemplate.com/printable/

## How to use it

1. Download the version you prefer.
2. Log one row per trade: date, symbol, side, entry, exit, size and your planned risk.
3. The sheet calculates P&L, R-multiple, win rate and drawdown for you.
4. Review the journal weekly to find what is working and what is not.
